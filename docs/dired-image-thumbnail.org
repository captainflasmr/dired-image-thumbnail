=dired-image-thumbnail= is an Emacs package that extends =image-dired=
with an enhanced workflow inspired by =dired-video-thumbnail=. It adds
powerful sorting, filtering, subdirectory management, and flexible
display options to the standard =image-dired= thumbnail viewer.

--------------

** 2 Features [[#Features-1][¶]]
:PROPERTIES:
:CUSTOM_ID: Features-1
:CLASS: chapter
:END:
- *Sorting* --- Sort thumbnails by name, date, size, or image dimensions
- *Filtering* --- Filter by name regexp, file size range, or dimension
  range
- *Subdirectory support* --- Works seamlessly with Dired's inserted
  subdirectories
- *Subdirectory helpers* --- Commands to quickly insert/remove
  subdirectories
- *Wrap display mode* --- Thumbnails flow naturally and wrap to window
  width
- *Enhanced header line* --- Shows current image info, dimensions,
  sort/filter status
- *Configurable window layout* --- Six layout presets (left-right,
  right-left, top-bottom, bottom-top, thumb-only, manual)
- *Display quality levels* --- Five quality tiers
  (full/high/fast/faster/draft) for speed vs fidelity trade-off
- *External-tool preview generation* --- Uses =djpeg=/=cjpeg= or
  =magick= for genuinely faster image previews
- *Image file validation* --- Magic-byte header checks and minimum file
  size to exclude corrupt files
- *Open in external editor* --- Press W to open an image in GIMP, Krita,
  or your system default
- *Auto-display navigation* --- Navigate with n/p to automatically show
  full-size images
- *Enhanced deletion* --- Delete and advance with C-d in both thumbnail
  and image buffers
- *Full integration* --- Works seamlessly with existing =image-dired=
  functionality
- *Transient menus* --- Optional =transient.el= integration for
  discoverability

*** 5.1 Quick Start [[#Quick-Start-1][¶]]
:PROPERTIES:
:CUSTOM_ID: Quick-Start-1
:CLASS: section
:END:
The simplest way to use =dired-image-thumbnail= is from a Dired buffer:

1. Navigate to a directory containing images
2. Press C-t d (or C-t m) to view thumbnails
3. Thumbnails appear on the left, full-size image on the right
4. Navigate with n/p to automatically view each image
5. Use the enhanced keybindings for sorting, filtering, etc.

--------------

*** 5.2 Working with Subdirectories [[#Working-with-Subdirectories-1][¶]]
:PROPERTIES:
:CUSTOM_ID: Working-with-Subdirectories-1

=dired-image-thumbnail= works with Dired's subdirectory insertion
feature. You have several options:

**** Manual insertion [[#Manual-insertion][¶]]
:PROPERTIES:
:CUSTOM_ID: Manual-insertion
:CLASS: subheading
:END:
Use Dired's built-in i (=dired-maybe-insert-subdir=) on any subdirectory
to make its contents visible, then run =dired-image-thumbnail=.

**** Helper commands [[#Helper-commands][¶]]
:PROPERTIES:
:CUSTOM_ID: Helper-commands
:CLASS: subheading
:END:
- C-t s (=dired-image-thumbnail-insert-image-subdirs=) --- Insert only
  subdirectories containing images (recommended)
- C-t z (=dired-image-thumbnail-insert-subdir-recursive=) --- Insert all
  subdirectories
- C-t k (=dired-image-thumbnail-kill-all-subdirs=) --- Remove all
  inserted subdirectories

*** 6.3 Quick Deletion Workflow [[#Quick-Deletion-Workflow-1][¶]]
:PROPERTIES:
:CUSTOM_ID: Quick-Deletion-Workflow-1
:CLASS: section
:END:
Press C-d in either the thumbnail or image display buffer to:

1. Get a confirmation prompt (unless =dired-image-thumbnail-auto-accept=
   is enabled)
2. Delete the current image file
3. Automatically advance to the next image
4. Continue browsing seamlessly

This makes culling large photo collections much faster than the standard
workflow.

** 8 Header Line [[#Header-Line-1][¶]]
:PROPERTIES:
:CUSTOM_ID: Header-Line-1
:CLASS: chapter

The enhanced header line displays:

- *Mark indicator* --- A ‘=*=' if the current image is marked
- *Filename* --- Relative to source directory when subdirectories are
  inserted
- *Image count* --- Current position / total (e.g., ‘=23/156=')
- *Dimensions* --- Width x Height in pixels (e.g., ‘=1920x1080=')
- *File size* --- Human-readable size (e.g., ‘=2.4M=')
- *Sort indicator* --- Current sort field and direction (e.g.,
  ‘=[name <]=')
- *Display quality* --- Current quality level (e.g., ‘=[fast]=')
- *Active filters* --- Description of any active filters
- *Marked count* --- Number of marked images (e.g., ‘=[3 marked]=')

*** 9.4 Display Quality [[#Display-Quality-1][¶]]
:PROPERTIES:
:CUSTOM_ID: Display-Quality-1
:CLASS: section
:END:
Control the speed/fidelity trade-off when navigating with n/p:

#+begin_src lisp-preformatted
(setq dired-image-thumbnail-display-quality 'fast) ; 'full, 'high, 'fast, 'faster, or 'draft
#+end_src

Lower quality levels use external tools (=djpeg=/=cjpeg= for JPEGs,
=magick= for others) to generate small preview files, so Emacs decodes
less data. Press Q in the thumbnail buffer to cycle through levels
interactively.

*** 9.5 Image Validation [[#Image-Validation-1][¶]]
:PROPERTIES:
:CUSTOM_ID: Image-Validation-1
:CLASS: section
:END:
Control which files are accepted as images:

#+begin_src lisp-preformatted
(setq dired-image-thumbnail-minimum-file-size 100) ; Minimum bytes (0 to disable)
(setq dired-image-thumbnail-validate-headers t)    ; Check magic bytes
#+end_src

When =dired-image-thumbnail-validate-headers= is non-nil, each candidate
file is opened briefly to verify that its first few bytes match a known
image format signature (JPEG, PNG, GIF, BMP, TIFF, WEBP, ICO,
HEIC/HEIF). SVG files are accepted without a byte check since they are
XML text.

(setq dired-image-thumbnail-auto-display-on-navigate t) ; Auto-display on n/p
#+end_src

When enabled (default), pressing n or p in the thumbnail buffer
automatically updates the image display buffer. When disabled, you must
press RET or C-RET to view full-size images.

interactive menus for sorting and filtering. These can be accessed with:

<<Subdirectory-Insertion>>
*** 14.1 Subdirectory Insertion [[#Subdirectory-Insertion][¶]]
:PROPERTIES:
:CUSTOM_ID: subdirectory-insertion
:CLASS: section
:END:
When working with large directory trees:

- Use =dired-image-thumbnail-insert-image-subdirs= (C-t s) instead of
  =dired-image-thumbnail-insert-subdir-recursive= (C-t z)
- The “smart” insertion only processes subdirectories containing images,
  which is much faster
- For very large collections, manually insert specific subdirectories
  with i as needed

<<Thumbnail-Generation>>
*** 14.2 Thumbnail Generation [[#Thumbnail-Generation][¶]]
:PROPERTIES:
:CUSTOM_ID: thumbnail-generation
:CLASS: section
:END:
First-time thumbnail generation can be slow for large images. Thumbnails
are cached by =image-dired=, so subsequent viewing is fast.

<<Display-Quality-and-Speed>>
*** 14.3 Display Quality and Speed [[#Display-Quality-and-Speed][¶]]
:PROPERTIES:
:CUSTOM_ID: display-quality-and-speed
:CLASS: section
:END:
Lower display quality levels (=faster=, =draft=) generate smaller
preview files using external tools, significantly reducing image decode
time. For large photo collections, set the quality to =draft= for the
fastest navigation, then switch to =full= when you want to examine an
image in detail.

<<Images-not-appearing>>
*** 15.1 Images not appearing [[#Images-not-appearing][¶]]
:PROPERTIES:
:CUSTOM_ID: images-not-appearing
:CLASS: section
:END:
- Ensure =image-dired= is working: test with C-t d in a directory with
  images
- Check that file extensions are in
  =dired-image-thumbnail-image-extensions=
- Verify thumbnails are being created in =image-dired-dir=
- If images have correct extensions but are corrupt, try setting
  =dired-image-thumbnail-validate-headers= to =nil=

<<Subdirectories-not-showing-images>>
*** 15.2 Subdirectories not showing images [[#Subdirectories-not-showing-images][¶]]
:PROPERTIES:
:CUSTOM_ID: subdirectories-not-showing-images
:CLASS: section
:END:
- Ensure subdirectories are actually inserted in the Dired buffer (use i
  or helper commands)
- Check that =dired-image-thumbnail-insert-image-subdirs= found
  subdirectories (watch for message)
- Verify files in subdirectories have recognized image extensions

<<Slow-performance-with-many-directories>>
*** 15.3 Slow performance with many directories [[#Slow-performance-with-many-directories][¶]]
:PROPERTIES:
:CUSTOM_ID: slow-performance-with-many-directories
:CLASS: section
:END:
- Use C-t s (insert image subdirs only) instead of C-t z (insert all
  subdirs)
- Manually insert specific subdirectories with i as needed
- Consider filtering to reduce the number of visible thumbnails
- Lower the display quality with Q for faster navigation

<<Layout-not-splitting-correctly>>
*** 15.4 Layout not splitting correctly [[#Layout-not-splitting-correctly][¶]]
:PROPERTIES:
:CUSTOM_ID: layout-not-splitting-correctly
:CLASS: section
:END:
- Ensure =dired-image-thumbnail-window-layout= is set to a layout symbol
  (default =left-right=)
- Try a different layout preset: =top-bottom=, =right-left=, etc.
- Set to =nil= and manage windows manually if other packages conflict
- Manually delete other windows with C-x 1 before launching

<<Auto_002ddisplay-not-working>>
*** 15.5 Auto-display not working [[#Auto_002ddisplay-not-working][¶]]
:PROPERTIES:
:CUSTOM_ID: auto-display-not-working
:CLASS: section
:END:
- Ensure =dired-image-thumbnail-auto-display-on-navigate= is =t=
  (default)
- The feature requires the split-screen layout to be active
- Try pressing RET on a thumbnail to manually trigger display
