Added texinfo documentation for future automatic installation through MELPA and created an Emacs manual.

If you want to see what the manual would look like, just download the docs directory from github, cd into it, and run:

#+begin_src bash
make
sudo make install-docs
#+end_src

Then calling up =info= =C-h i= and dired-image-thumbnail will be present in the Emacs menu, or just select =m= and search for =dired-image-thumbnail=

For those interested in the manual, I have converted it into html format, which is accessible here:

[[file:dired-image-thumbnail.org]]

It has been converted using the following command:

#+begin_src bash
makeinfo --html --no-split dired-image-thumbnail.texi -o dired-image-thumbnail.html
pandoc -f html -t org -o dired-image-thumbnail.org dired-image-thumbnail.html
#+end_src
