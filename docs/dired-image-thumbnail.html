1 Introduction ¶

dired-image-thumbnail is an Emacs package that extends image-dired with an enhanced workflow inspired by dired-video-thumbnail. It adds powerful sorting, filtering, subdirectory management, and flexible display options to the standard image-dired thumbnail viewer.

Next: Requirements, Previous: Introduction, Up: dired-image-thumbnail   [Contents]

2 Features ¶

  • Sorting — Sort thumbnails by name, date, size, or image dimensions
  • Filtering — Filter by name regexp, file size range, or dimension range
  • Subdirectory support — Works seamlessly with Dired’s inserted subdirectories
  • Subdirectory helpers — Commands to quickly insert/remove subdirectories
  • Wrap display mode — Thumbnails flow naturally and wrap to window width
  • Enhanced header line — Shows current image info, directory location, dimensions, sort/filter status, and quality level
  • Configurable window layout — Six layout presets (left-right, right-left, top-bottom, bottom-top, thumb-only, manual)
  • Display quality levels — Five quality tiers (full/high/fast/faster/draft) for speed vs fidelity trade-off
  • External-tool preview generation — Uses djpeg/cjpeg or magick for genuinely faster image previews
  • Image file validation — Magic-byte header checks and minimum file size to exclude corrupt files
  • Open in external editor — Press W to open an image in GIMP, Krita, or your system default
  • Auto-display navigation — Navigate with n/p to automatically show full-size images
  • Enhanced deletion — Delete and advance with C-d in both thumbnail and image buffers
  • Full integration — Works seamlessly with existing image-dired functionality
  • Transient menus — Optional transient.el integration for discoverability

5.1 Quick Start ¶

The simplest way to use dired-image-thumbnail is from a Dired buffer:

  1. Navigate to a directory containing images
  2. Press C-t d (or C-t m) to view thumbnails
  3. Thumbnails appear on the left, full-size image on the right
  4. Navigate with n/p to automatically view each image
  5. Use the enhanced keybindings for sorting, filtering, etc.

Next: From Standard image-dired, Previous: Quick Start, Up: Usage   [Contents]

5.2 Working with Subdirectories ¶

dired-image-thumbnail works with Dired’s subdirectory insertion feature. You have several options:

Manual insertion ¶

Use Dired’s built-in i (dired-maybe-insert-subdir) on any subdirectory to make its contents visible, then run dired-image-thumbnail.

Helper commands ¶

  • C-t s (dired-image-thumbnail-insert-image-subdirs) — Insert only subdirectories containing images (recommended)
  • C-t z (dired-image-thumbnail-insert-subdir-recursive) — Insert all subdirectories
  • C-t k (dired-image-thumbnail-kill-all-subdirs) — Remove all inserted subdirectories

Previous: Working with Subdirectories, Up: Usage   [Contents]

5.3 From Standard image-dired ¶

You can also use the standard image-dired commands (C-t d, C-t a, etc.) — dired-image-thumbnail automatically enhances the thumbnail buffer with new keybindings.

6 Enhanced Workflow ¶

dired-image-thumbnail provides an enhanced grid-view workflow that improves upon standard image-dired.

6.1 Automatic Split-Screen Layout ¶

When you launch dired-image-thumbnail (or use standard image-dired with this package loaded): 

+------------------+------------------------+
|  Thumbnails      |  Full-size Image       |
|  (Left 40%)      |  (Right 60%)           |
|                  |                        |
|  [img1] <--      |  +------------------+  |
|  [img2]          |  |                  |  |
|  [img3]          |  |   Current Image  |  |
|  [img4]          |  |                  |  |
|  [img5]          |  +------------------+  |
|                  |                        |
+------------------+------------------------+

The layout is controlled by dired-image-thumbnail-window-layout (default left-right) and dired-image-thumbnail-window-ratio (default 0.4).

Next: Quick Deletion Workflow, Previous: Automatic Split-Screen Layout, Up: Enhanced Workflow   [Contents]

6.2 Auto-Display Navigation ¶

With dired-image-thumbnail-auto-display-on-navigate enabled (default):

  • Press n or p to navigate thumbnails
  • The full-size image automatically updates on the right
  • No need to press RET or C-RET for each image
  • Smooth, fluid browsing experience

Previous: Auto-Display Navigation, Up: Enhanced Workflow   [Contents]

6.3 Quick Deletion Workflow ¶

Press C-d in either the thumbnail or image display buffer to:

  1. Get a confirmation prompt (unless dired-image-thumbnail-auto-accept is enabled)
  2. Delete the current image file
  3. Automatically advance to the next image
  4. Continue browsing seamlessly

This makes culling large photo collections much faster than the standard workflow.

8 Header Line ¶

The enhanced header line displays:

  • Mark indicator — A ‘*’ if the current image is marked
  • Filename — Relative to source directory when subdirectories are inserted
  • Directory — Location of the current image, abbreviated (e.g., ‘~/Photos/’); falls back to the source directory
  • Image count — Current position / total (e.g., ‘23/156’)
  • Dimensions — Width x Height in pixels (e.g., ‘1920x1080’)
  • File size — Human-readable size (e.g., ‘2.4M’)
  • Sort indicator — Current sort field and direction (e.g., ‘[name <]’)
  • Display quality — Current quality level (e.g., ‘[fast]’)
  • Active filters — Description of any active filters
  • Marked count — Number of marked images (e.g., ‘[3 marked]’)

9.1 Default Sort Settings ¶

(setq dired-image-thumbnail-sort-by 'dired)       ; 'dired, 'name, 'date, 'size, or 'dimensions
(setq dired-image-thumbnail-sort-order 'ascending) ; 'ascending or 'descending

Next: Window Layout, Previous: Default Sort Settings, Up: Customization   [Contents]

9.2 Display Options ¶

(setq dired-image-thumbnail-wrap-display nil) ; Enable wrap display by default

Next: Display Quality, Previous: Display Options, Up: Customization   [Contents]

9.3 Window Layout ¶

Control the split-screen layout and thumbnail/image ratio: 

(setq dired-image-thumbnail-window-layout 'left-right) ; 'left-right, 'right-left, 'top-bottom, 'bottom-top, 'thumb-only, or nil
(setq dired-image-thumbnail-window-ratio 0.4)          ; Fraction of frame for thumbnails

Set to nil to disable automatic layout management and use your own display-buffer-alist rules.

Next: Image Validation, Previous: Window Layout, Up: Customization   [Contents]

9.4 Display Quality ¶

Control the speed/fidelity trade-off when navigating with n/p: 

(setq dired-image-thumbnail-display-quality 'faster) ; 'full, 'high, 'fast, 'faster, or 'draft

Lower quality levels use external tools (djpeg/cjpeg for JPEGs, magick for others) to generate small preview files, so Emacs decodes less data. Press Q in the thumbnail buffer to cycle through levels interactively.

Next: External Editor, Previous: Display Quality, Up: Customization   [Contents]

9.5 Image Validation ¶

Control which files are accepted as images: 

(setq dired-image-thumbnail-minimum-file-size 100) ; Minimum bytes (0 to disable)
(setq dired-image-thumbnail-validate-headers t)    ; Check magic bytes

When dired-image-thumbnail-validate-headers is non-nil, each candidate file is opened briefly to verify that its first few bytes match a known image format signature (JPEG, PNG, GIF, BMP, TIFF, WEBP, ICO, HEIC/HEIF). SVG files are accepted without a byte check since they are XML text.

Next: Navigation Behavior, Previous: Image Validation, Up: Customization   [Contents]

9.6 External Editor ¶

Set a specific program for W to open images with: 

(setq dired-image-thumbnail-external-editor "gimp") ; nil for system default

When nil (default), the system default application is used via xdg-open on Linux, open on macOS, or start on Windows.

Next: Auto-Accepting Actions, Previous: External Editor, Up: Customization   [Contents]

9.7 Navigation Behavior ¶

Control whether navigating with n/p automatically displays full-size images: 

(setq dired-image-thumbnail-auto-display-on-navigate t) ; Auto-display on n/p

When enabled (default), pressing n or p in the thumbnail buffer automatically updates the image display buffer. When disabled, you must press RET or C-RET to view full-size images.

Next: Image Extensions, Previous: Navigation Behavior, Up: Customization   [Contents]

9.8 Auto-Accepting Actions ¶

Control whether to skip confirmation prompts for file actions: 

(setq dired-image-thumbnail-auto-accept nil) ; Require confirmation (default)

When enabled, actions like deleting files (D, C-d, x) will proceed without asking for confirmation.

(setq dired-image-thumbnail-image-extensions

13 Transient Menu Support ¶

If transient is available, dired-image-thumbnail provides interactive menus for sorting and filtering. These can be accessed with:

  • s / S — Sort (completing-read: dired/name/date/size/reverse)
  • / — Filter (completing-read: name/size/clear)

To disable transient menus even when transient is installed, don’t load dired-image-thumbnail-transient.el.

14 Performance Notes ¶

  • Subdirectory Insertion
  • Thumbnail Generation
  • Display Quality and Speed

14.1 Subdirectory Insertion ¶

When working with large directory trees:

  • Use dired-image-thumbnail-insert-image-subdirs (C-t s) instead of dired-image-thumbnail-insert-subdir-recursive (C-t z)
  • The “smart” insertion only processes subdirectories containing images, which is much faster
  • For very large collections, manually insert specific subdirectories with i as needed
  • From the thumbnail buffer, z (or the transient menu’s Other group) inserts subdirectories recursively into the associated dired buffer; the C-t s / C-t z / C-t k variants remain available from dired

14.2 Thumbnail Generation ¶

First-time thumbnail generation can be slow for large images. Thumbnails are cached by image-dired, so subsequent viewing is fast.

14.3 Display Quality and Speed ¶

Lower display quality levels (faster, draft) generate smaller preview files using external tools, significantly reducing image decode time. For large photo collections, set the quality to draft for the fastest navigation, then switch to full when you want to examine an image in detail.

15 Troubleshooting ¶

  • Images not appearing
  • Subdirectories not showing images
  • Slow performance with many directories
  • Layout not splitting correctly
  • Auto-display not working

15.1 Images not appearing ¶

  • Ensure image-dired is working: test with C-t d in a directory with images
  • Check that file extensions are in dired-image-thumbnail-image-extensions
  • Verify thumbnails are being created in image-dired-dir
  • If images have correct extensions but are corrupt, try setting dired-image-thumbnail-validate-headers to nil

15.2 Subdirectories not showing images ¶

  • Ensure subdirectories are actually inserted in the Dired buffer (use i or helper commands)
  • Check that dired-image-thumbnail-insert-image-subdirs found subdirectories (watch for message)
  • Verify files in subdirectories have recognized image extensions

15.3 Slow performance with many directories ¶

  • Use C-t s (insert image subdirs only) instead of C-t z (insert all subdirs)
  • Manually insert specific subdirectories with i as needed
  • Consider filtering to reduce the number of visible thumbnails
  • Lower the display quality with Q for faster navigation

15.4 Layout not splitting correctly ¶

  • Ensure dired-image-thumbnail-window-layout is set to a layout symbol (default left-right)
  • Try a different layout preset: top-bottom, right-left, etc.
  • Set to nil and manage windows manually if other packages conflict
  • Manually delete other windows with C-x 1 before launching

15.5 Auto-display not working ¶

  • Ensure dired-image-thumbnail-auto-display-on-navigate is t (default)
  • The feature requires the split-screen layout to be active
  • Try pressing RET on a thumbnail to manually trigger display
